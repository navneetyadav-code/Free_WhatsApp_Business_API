# Code of Conduct

This project welcomes respectful collaboration from developers of all experience levels.

## Expected Behavior

- Be clear, constructive, and respectful.
- Assume good intent when reviewing issues and pull requests.
- Keep discussions focused on the project, code quality, security, and platform safety.
- Avoid sharing private credentials, phone numbers, session files, or unrelated personal data.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Posting secrets, private user data, or WhatsApp session files.
- Encouraging spam, abuse, or behavior that ignores user consent.

## Reporting

If a discussion becomes unsafe or harmful, contact the project maintainer privately with links and context.
